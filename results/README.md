# Interpreting the finite comparisons

**Current paper:** [`checked-comparisons.csv`](checked-comparisons.csv) supplies both Appendix A tables. Table 1 compares the project count `W` with the strongest **analytic or coordinate-backed** external count `B_checked` among the specified sources. Table 2 separately records stronger **unverified forum reports** on four sides. Do not combine the two tiers when citing verified lower bounds.

- **C and R (analytic):** `3(q−1)` on side `2q` for prime `q` (Hall–Jackson–Sudbery–Wild) and `6(q−1)` on side `4q` for prime `q ≡ 1 mod 12` (four-period ring). A source with `b` points on side `a` gives at least `b−4 max(a−n,0)` on side `n`. These bounds increase up to the target scale and then decrease, so the neighbouring admissible primes suffice.
- **K (coordinates):** 146 version-pinned sets from paper 22 v4. `p22-crops.csv` records the maximum actual count in any axis-aligned target square in each larger source, with a maximizing lower-left corner. On side 293 the 504 points come from a side-300 set of 524 points, in the crop `[3,295]²`.
- **S (coordinates reconstructed and checked):** the three public frames in paper 47 §8, with 282, 421 and 810 insertions, giving 24,306, 48,421 and 96,816 points at their source sides. The transfer above applies at other sides. A larger project count after deletions and insertions is not a literal extension.
- **F (report only):** `forum-counts.csv` records point counts, source sides and dated posts; `source-register.csv` gives versions and exact locators. On sides 293, 389, 773 and 4037 the strongest checked comparisons are **504, 576, 1152 and 6048**. The corresponding stronger transfers **512, 652, 1244 and 6118** depend on the forum reports; no coordinate certificate was located for any of those four counts.

`W` is an exhibited, checked construction, not an optimum. Q/H/U describes the project witness only; an embedding or crop need not preserve symmetry about the new board centre. `W−3n/2` is the excess at the actual side, **not** either comparison difference. All boards use ordinary Euclidean collinearity and zero-based coordinates.

**Reproduce.** Run `python3 scripts/review_tables.py` from the repository root to recompute the two tiers and compare the CSV and rendered table inputs. `--write` regenerates those files. To audit the underlying external coordinates, restore the pinned supplements with `python3 scripts/restore_inputs.py --group station --fetch`, then run `python3 scripts/comparison.py --audit-sources` and `python3 scripts/check_public_frames.py`. R4 also supplies `python3 scripts/recheck_benchmarks.py .cache/upstream` (NumPy). It reads the pinned source archives directly, using integer slope bins and prefix sums rather than the original geometry and crop checkers. [Output](../verification/r4-benchmarks.txt).

**Historical replay convention:** [`lower-bounds.csv`](lower-bounds.csv), `paper/table-ring.tex` and `paper/table-other.tex` are retained exactly as generated by `scripts/comparison.py` for the immutable R2 kit. Its `B_ref` takes the maximum *including* reports. The kit's original results documentation is preserved in [`replay/results-README-r2.md`](../replay/results-README-r2.md); its 15 witness counts coincide exactly with the current ones. Neither table is a live ranking.
