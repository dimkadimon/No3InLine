# Manuscript · R3

**Dmitry Kamenetsky, *A super-polylogarithmic excess in the no-three-in-line problem*.** Illustrated working manuscript. Author review is ongoing; this is not a statement of acceptance, formal verification or arXiv submission. [Response to the updated review](../REVISION.md) · [Diagrams and their data](FIGURES.md).

- `main.pdf` is the reader edition with an attached copy of `no3-replay-r2.zip`. Save it from the attachments pane, use `pdfdetach -save 1 -o replay.zip main.pdf`, or download the identical [commit-pinned replay ZIP](https://raw.githubusercontent.com/dimkadimon/No3InLine/e19b8a1b689eba392c7d26ec3733e88db566dc0e/paper/anc/no3-replay-r2.zip).
- `arxiv-source.tar.gz` has 13 files: seven TeX inputs including the single root `main.tex`, four prebuilt vector figures, and two ancillary files (`anc/README.txt` and the replay ZIP). There is no Appendix B or separate availability section. TeX **does not read `anc/`**. A TeX-only processor produces the same pages without the optional embedded ZIP; the ancillary download is separate. See [arXiv ancillary-file guidance](https://info.arxiv.org/help/ancillary_files.html).
- `proof.tex` and `collisions.tex` contain the analytic argument; `examples.tex` is the sole appendix, on finite witnesses and comparisons. `references.tex` is the bibliography. The two table fragments are generated by `../scripts/comparison.py`; the dagger on the four reported F cells is applied only in typesetting, without changing the independently replayed data.
- `figures/` holds vector artwork. `python3 scripts/construction_diagrams.py --previews paper/figures/previews` regenerates the three new diagrams and endpoint ledger. `python3 scripts/figure.py` regenerates the original before/after figure. Only redrawing, not compiling or reading the paper, needs Matplotlib.

**Build.** From a fresh unpack of the tarball run `pdflatex -no-shell-escape main.tex` three times. Use standard AMS, Latin Modern, microtype, geometry, booktabs, tabularx, graphicx, xcolor and hyperref. There is no shell escape, network requirement, custom class or BibTeX dependency. From a full checkout `python3 scripts/build_paper.py` builds and independently unpacks the archive, runs pdfLaTeX, and uses qpdf and Poppler to attach and extract the exact kit and check the reader's page text. Byte-identical PDF output is expected on the recorded toolchain, not across arbitrary font/TeX versions.

**Versions.** R3 uses tag `review-r3` of [dimkadimon/No3InLine](https://github.com/dimkadimon/No3InLine). Its finite kit is unchanged from data commit `e19b8a1b689eba392c7d26ec3733e88db566dc0e`. The earlier 18-page R2 manuscript is at `af6b6eda4f20ba6d9bc977c0c57c292eb82841de`; the 12-page initial version is at `27975940dc0d3201c3b2dda0a230c52740ec25f6`. Numerical checks attest to the specified finite data only. No DOI is asserted.
