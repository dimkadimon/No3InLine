# Finite replay · R2 · 19 November 2026

Accompanies Dmitry Kamenetsky, *A super-polylogarithmic excess in the no-three-in-line problem*. This is a standalone subset of the project, **not** a proof checker for the asymptotic result. It contains the data and independently implemented integer checks needed for every project row of the paper. No solver or online service is needed for those checks. The mathematical proof, including the counting lemmas, is in the paper.

Unzip `no3-replay-r2.zip` into an empty directory and work at its root. Use Python 3.9 or newer (no `-O`), a C++17 compiler named `c++` or specified by `CXX`, and enough memory for the largest direction sort (several hundred MB). These scripts compile the C++ checkers to a temporary directory. The two small TeX table-row fragments are included as plain-text reference outputs, not typesetting inputs. No raw third-party seed archive is embedded.

```sh
python3 scripts/verify_release.py --hashes-only  # compare every kit member to MANIFEST.sha256
python3 scripts/comparison.py                   # check every CSV/printed table row and source transfer
python3 scripts/audit_counting.py               # small exact tests of the counting algebra, NOT the theorem
python3 scripts/verify_release.py               # regenerate matching & check all 15 project counts, offline
```

## Finding and reconstructing a set

In `results/lower-bounds.csv` choose the row with the desired `n`. The final column is its exact coordinate list or edit certificate; the benchmark columns name the external input and its transfer. Coordinates are zero based; no wraparound. `verification/` contains selected transcripts. The mathematical role of each comparator and the source IDs, dates and locators are in `results/README.md` and `results/source-register.csv`.

- **Raw witnesses.** CSVs with header `x,y` are themselves coordinate certificates. These include sides 201, 202, 293, 389, 4037 and 10085. `studies/improvements/data/orbits{293,389}.csv` stores one point from each orbit: rotate by `(x,y) -> (n-1-y,x)` up to four times. The verifier checks this expansion. The JSON recipes `studies/larger-grids/data/extension-n{201,202}.json` specify the source and translated insertions for the two side-200-based extensions. After restoring the versioned station inputs below, run `python3 studies/larger-grids/code/verify_small.py` to rebuild those two sets and check every determinant (also checks the bundled legacy controls).
- **Two-period frame edits (five large sides).** A certificate header is `p removals additions`, followed by the removed and added coordinates. The base is `0 <= x,y < 2p`, `x(y-h) = 1 mod p`, `h=(p-1)/2`, excluding the central square `h < x,y <= h+p`. `studies/improvements/data/final-P.txt` contains the final lists at `P=8009,16001,32003`; `studies/larger-grids/data/edits_P.txt` supplies `P=65537,500009`. Compile `c++ -O3 -std=c++17 studies/improvements/code/verify_frame.cpp -o frame`, then e.g. `./frame studies/larger-grids/data/edits_65537.txt n131074.csv`. This writes the sorted CSV and verifies its geometry. `python3 scripts/verify_release.py --expand-large` also writes both omitted large two-period CSVs and checks their historical hashes.
- **Four-period anchored rings.** `small-prime-examples/certificates/p73.txt`, for example, is the 450-point illustration, **not** the 508-point witness on that side. Six small rings have both CSVs and certificates. Header `p k m f` precedes `m` representative pairs of coordinates and `f` labels. Each label is the least residue in the component generated by `u -> 3u, -u, k/u`. Flip those components in the square-abscissa-even orientation, then add the eight anchors and the representatives and their opposite mates. The special matching certificate is `unbounded-gain/data/certificate.txt`. To expand its 4,782,972 points to a sorted, 72,488,790-byte CSV:

  ```sh
  python3 scripts/expand_ring.py unbounded-gain/data/certificate.txt n3188645.csv
  # SHA256: 7672b789660d53c4737a690111dd1b641f90191756ebc1bb52a6b8e289957d1d
  ```

  For the independent replay of its construction and check separately:

  ```sh
  c++ -O3 -std=c++17 unbounded-gain/code/match_example.cpp -o match
  ./match > rebuilt.cert 2> rebuilt-matching.txt
  cmp rebuilt.cert unbounded-gain/data/certificate.txt
  cmp rebuilt-matching.txt unbounded-gain/data/matching.txt
  c++ -O3 -std=c++17 unbounded-gain/code/verify_example.cpp -o check-ring
  ./check-ring < rebuilt.cert
  ```

  The first program reconstructs 144 clauses and 38 flips. The other reads only the certificate, checks the eight possible old directions and all 57,395,652 directions at the twelve special sites. The older scripts in `unbounded-gain/code/` test identities and replay the finite candidate search. They do not claim that this search imposed all 130 signs.

## Checking the external comparisons

C/R are constructions in the references. K/S are data-backed: the two version-specific download URLs and ZIP SHA-256s are in `THIRD_PARTY.md` and `scripts/restore_inputs.py`. For example:

```sh
python3 scripts/restore_inputs.py --group station --fetch
python3 scripts/comparison.py --audit-sources     # 146 K seed geometries and all relevant crop maxima
python3 scripts/check_public_frames.py           # all three S baselines, before project edits
```

Supply `--cache DIR` instead of `--fetch` if you already have the pinned `22.zip` and `47.zip`. For **F**, `results/forum-counts.csv` gives the exact reported counts and comment locators, not unpublished coordinates. Replaying their arithmetic is not a geometry check of the underlying reports. Positive and negative differences are kept.

The unchanged historical certificates/coordinates and core reconstruction/check programs come from local project base `27975940dc0d3201c3b2dda0a230c52740ec25f6`. The R2 additions and every distributed input are identified by the kit manifest; the manuscript also gives the kit ZIP digest and the finite-data Git revision. Source reuse is subject to `THIRD_PARTY.md`, not a relicensing of upstream data. The full bundle contains the working history, historical notes and search logs intentionally omitted from this kit. There is no claimed public DOI or arXiv deposit for this working version.
